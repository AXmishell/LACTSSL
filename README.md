# LACTSSL

面向企业团队与个人 / 小团队的自托管 SSL 证书管理平台：ACME 申请与自动续期、证书部署、站点证书监控、通知，以及内部私有 CA / ACME 服务。企业用它统一多业务线证书治理，个人开发者、站长和小团队用一台小主机即可完成自动续期与部署。

完整文档：<https://lactssl.gpcn.cc/>

文档提供以下语言版本：简体中文（`/zh/`）、English（`/`）、繁體中文（`/zh-hant/`）、日本語（`/ja/`）、Русский（`/ru/`）。

## 适用场景

- 个人站点、博客、副业项目和家庭实验室的证书自动续期与部署。
- 多域名、多业务线证书的集中签发、续期和交付。
- 内网服务的私有 CA 签发，以及面向 certbot / lego / acme.sh 的标准 ACME 端点。
- 证书到期治理、部署失败告警和审计留痕。
- 通过 API 密钥接入 CI/CD、CMDB、巡检和证书分发。

## 交付边界

- 自托管单实例、单租户、单管理员账户；个人场景一台 1 vCPU / 1 GB 的小主机或 NAS 即可运行。
- API 密钥按 `资源:动作` 分权，适合机器身份；不提供多用户 RBAC、SSO、多租户。
- 数据库支持 SQLite（默认）、PostgreSQL 18 与 MySQL 5.7+；SQLite 单写，不提供内置双活集群，生产建议单活 + 加密备份 + 恢复演练。
- 私钥在本地数据库加密存储；不提供 HSM/KMS 托管。
- 不附带等保、ISO 27001 等认证证书。

## 仓库结构

- 本仓库：插件宿主、官方 DNS / 部署 / 通知插件实现、ACME、部署编排、通知、Web UI。
- 官方插件实现位于 `internal/plugin/`，随主模块编译；`plugins/` 是外部插件开发 SDK（协议、helper 框架与通用工具），发布物为单一主程序。

官方 DNS / 部署 / 通知插件已编译进主程序；DNS 服务商默认全部停用，需在插件页按需启用，部署/通知也按类别和条目启停。主程序不再依赖外部插件仓库，也不再提供在线索引与插件市场。仍保留上传第三方 helper 的能力，上传插件默认在 Linux Landlock / rlimit 受限环境中执行；不支持 strict 沙箱的平台自动降级为 basic 资源限制。

插件执行仍遵循协议 v1：内置实现直接调用，上传插件通过一次性子进程通信。
