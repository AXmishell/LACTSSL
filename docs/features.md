# 产品能力

本文按业务能力说明 LACTSSL 能做什么、关键参数和限制，便于方案设计和验收。具体操作步骤分散在[评估与上线](getting-started.md)、[管理工作台](administration.md)和[API 集成](api.md)中。

## 能力地图

| 能力域 | 主要内容 | 典型使用方 |
| --- | --- | --- |
| 证书资产 | 公共 CA 申请、自动续期、证书详情与清理 | 平台/运维 |
| 任务编排 | 申请 → 部署（可多个）→ 通知 | 平台/运维 |
| 证书交付 | 本地目录、SSH/SFTP、FTP、Webhook、云 CDN、面板 | 平台/运维、业务系统 |
| 内部 PKI | 私有 CA 生成/导入、层级、CRL/OCSP 地址 | 安全、基础设施 |
| ACME 服务端 | 对内提供标准 ACME v2 端点 | 内部平台、设备、测试环境 |
| 监控与告警 | 外部站点证书监控、任务/部署通知 | 运维、值班 |
| 审计与恢复 | 操作日志、系统日志、加密备份 | 安全、审计、运维 |
| 集成 | API 密钥、REST API、自动化 | 集成开发 |

## 1. 证书申请与续期

### 1.1 验证方式

- 公共 CA 申请仅使用 **DNS-01** 验证，支持单域名、多域名和通配符证书。
- DNS-01 需要在「DNS 账户」中配置服务商 API 凭据，任务运行时自动创建/清理 TXT 记录。
- 私有 CA 签发不经过 ACME 验证，由系统直接签发。
- 内置 ACME 服务端支持 HTTP-01、DNS-01、TLS-ALPN-01，供内部客户端使用。

### 1.2 内置证书颁发机构

| CA | 说明 |
| --- | --- |
| Let's Encrypt | 默认公共 CA，无需 EAB |
| ZeroSSL | 需要 EAB |
| Google Trust Services | 需要 EAB |
| Buypass | 公共 CA |
| LiteSSL | 需要 EAB |

「权威CA」中还可以添加多个**通用 ACME 上游**：

- 配置 ACME 目录地址、ACME v1/v2 协议版本和可选 EAB。
- 通用上游会出现在任务和默认 CA 选择列表中。
- 自定义目录地址必须使用 HTTPS；只有本机回环允许 HTTP。
- ACME v1 仅支持 DNS-01，且不支持 EAB。

### 1.3 密钥与续期

- 私钥类型：`ecdsa`（默认）、`ecdsa384`、`rsa2048`、`rsa4096`。
- 自动续期默认在到期前 30 天触发，可按任务调整。
- 后台调度器每 30 秒检查到期任务。
- 任务失败可在任务日志中查看原因；凭据、域名和 CA 问题会给出明确错误。
- 证书管理页支持搜索、状态筛选、详情和安全分析。
- 下载证书链、查看或下载私钥都依赖登录会话；API 调用下载证书链需要 `certificates:read`，查看或下载私钥还需要 `certificates:key`。
- 一键清理可按状态（已过期、已撤销或全部）、时长、签发时间、域名、颁发机构、来源和“保留每个任务最新证书”筛选；清理后相关任务的证书引用会被清空。

### 1.4 默认配置

「权威CA」支持配置：

- ACME 账户邮箱。
- 默认 CA。
- 默认私钥类型。
- 默认续期天数。
- 各 CA 的 EAB 凭据。

## 2. DNS 服务商

DNS 服务商由 DNS 插件提供。主程序不内置任何服务商，安装并启用插件后，服务商列表才会出现。

常见服务商及凭据：

| 服务商 | 主要凭据 |
| --- | --- |
| 阿里云 DNS（alidns） | AccessKey ID / Secret，可选 Region |
| 阿里云 ESA（aliesa） | AccessKey ID / Secret，可选 Region |
| Cloudflare | API Token，或 Email + Global API Key，可选 API 上游地址 |
| DNSPod | API Token |
| 腾讯云（tencentcloud） | SecretId / SecretKey，可选 Region |
| 华为云（huaweicloud） | AccessKey ID / SecretAccessKey / Region |
| 火山引擎（volcengine） | AccessKey / SecretKey，可选 Region、API 主机与协议 |
| AWS Route 53 | AccessKey / SecretAccessKey，可选 Region、Hosted Zone、私有区域 |
| Google Cloud DNS | 服务账号 JSON，可选项目 ID |
| Azure DNS | Tenant ID / Client ID / Client Secret / Subscription ID / 资源组 |
| 西部数码（westcn） | 用户名 / 密码 |
| PowerDNS（pdns） | API 地址 / API Key，可选 Server 名称与 API 版本 |
| RFC 2136 动态更新 | DNS 服务器，可选 TSIG Key / Secret / 算法与 Zone 列表 |

- 安装官方 DNS 插件后支持 lego 的全部服务商（约 190 家）。
- `manual` 服务商需要人工添加 TXT 记录，不纳入自动流程。
- 凭据在写入数据库前加密；编辑时留空密钥字段表示保留原值。
- Cloudflare、DNSimple、PowerDNS、火山引擎等支持自定义 API 上游地址，可用于代理、自建服务或兼容网关。
- 完整服务商列表以「DNS 账户」页的服务商下拉框为准。

插件安装、离线镜像和供应链治理见[插件治理](plugins.md)与[DNS 插件](dns-plugins.md)。

## 3. 任务编排

任务由节点组成，默认流程是「申请 → 部署（可多个）→ 通知」。

| 节点 | 关键参数 |
| --- | --- |
| 申请 | 域名、DNS 账户、CA、私钥类型、自动续期、提前天数 |
| 部署 | 目标凭据、证书/私钥路径、站点/域名/证书名称、重载命令 |
| 通知 | 渠道、触发时机（始终 / 仅成功 / 仅失败） |

要点：

- 节点可以启用/禁用和排序；任务可以包含多个部署节点，把同一张证书交付到多个目标。
- 旧任务没有显式流程时，系统会根据原有域名、目标凭据等字段推导等效流程。
- 升级时会把旧凭据中的部署路径、站点和域名迁移到任务部署节点，再清理凭据中的部署参数。
- 任务列表支持表头全选和多选，可批量执行、暂停或启动自动续期。
- 批量执行会跳过正在运行的任务；批量启停只调整调度状态，不中断已经开始的签发。

## 4. 证书部署

「目标凭据」只保存认证与连接信息；证书路径、重载命令、部署域名、站点等参数在任务部署节点中填写。因此同一凭据可以被多个任务复用。

### 4.1 内置目标

| 目标 | 凭据 | 部署参数 |
| --- | --- | --- |
| 本地目录 | 无 | 证书/私钥路径，可选重载命令 |
| SSH / SFTP | 主机、端口、用户名、密码或私钥、主机指纹 | 远程证书/私钥路径，可选远程重载命令 |

SSH 默认要求填写目标主机指纹（`SHA256:...`）。只有显式开启“首次连接自动信任主机密钥”时才采用 TOFU 记录；后续指纹不一致会拒绝连接。

### 4.2 插件目标

以下目标由部署插件提供，安装并启用后可用：

- FTP / FTPS：支持普通 FTP、显式 TLS、隐式 TLS。
- Webhook：回调地址、自定义认证头、是否跳过 TLS 校验。
- 阿里云 CDN、七牛云、宝塔面板、1Panel、雷池 WAF 等。
- 具体产品和参数在任务部署节点的「部署对象」中选择。

部署插件会接收证书与私钥，等同受信代码，默认关闭。未安装插件时只显示本地文件与 SSH；历史凭据仍会保留。

### 4.3 部署记录

- 每次部署生成部署记录，可在证书详情和日志中查看结果。
- 手动部署优先复用证书所属任务的部署节点参数，也可以按目标单独填写本次参数。
- 本地/SSH 部署会执行重载命令，API 密钥必须显式拥有 `deploy:execute` 才能触发。
- 部署失败不会自动回滚目标系统上的旧证书；需要在目标侧保留上一版文件或使用原子发布机制。

## 5. 站点证书监控

添加外部站点后，服务会定期通过 TLS 连接读取证书：

- 目标支持 `example.com`、`example.com:8443` 或完整 URL，默认端口 `443`。
- 默认每 24 小时检查一次，可按监控项调整。
- 校验证书主机名、签发者、到期时间和状态。
- 剩余 30 天以内标记为即将过期；过期、连接失败、链不受信任、链不完整或主机名不匹配标记为异常。
- 状态从正常变为即将过期、已过期或异常时发送通知。
- 监控会校验系统信任链，避免中间人用自签证书掩盖真实证书问题。

## 6. 通知

### 6.1 内置渠道

- **邮件（SMTP）**：服务器、端口、用户名、密码、发件人，支持 SSL。
- 默认使用隐式 TLS（`smtp.ssl=true`）；关闭隐式 TLS 时，如果服务器不支持 STARTTLS，服务会拒绝发送，避免重置令牌等敏感邮件明文传输。

### 6.2 插件渠道

Gotify、ServerChan、ntfy、GoCQHTTP、PushDeer、Bark、Telegram、钉钉、企业微信机器人、企业微信应用、企业微信智能机器人、iGot、PushPlus、WePlus、WxPusher、WxPusher SPT、OpenILink、WPush、Synology Chat、飞书、PushMe、ChronoCat，以及通用自定义 Webhook。

- 除邮件外的渠道由通知插件提供。
- 渠道可以单独启用并发送测试消息。
- 任务通知节点可选择具体渠道，或使用全部已启用渠道。
- 触发时机支持始终、仅成功、仅失败。

## 7. 私有 CA

在「私有CA」中管理内部证书颁发机构。

### 7.1 生成

- 私钥类型：ECDSA P-256 / P-384、RSA 2048 / 4096。
- 有效期按需要设置。
- 可生成根 CA，也可选择「中间/颁发 CA」，由已有私有 CA 签发下级 CA。
- 生成时可配置完整 X.509 字段与 PKI 参数：
  - 主题：ST、L、OU、Email、自定义序列号。
  - 扩展：路径长度、Key Usage、Extended Key Usage、SAN（DNS/IP）、Name Constraints（允许/排除的 DNS 域与 IP 网段）。
  - 基础设施：上级 CA、CRL 分发点、OCSP 响应地址、CA 颁发者地址、证书策略 OID 与 CPS 地址。
- SKI、AKI、CA 基本约束由系统自动生成。
- 选择上级 CA 时，有效期和路径长度会自动收敛到上级 CA 允许的范围。

### 7.2 导入

- 粘贴 PEM 格式的 CA 证书与私钥。
- 校验 CA 基本约束、证书签名用途、证书与私钥是否匹配。
- 导入中间 CA 时可选择上级 CA，系统会校验签名并建立层级关系。

### 7.3 下载与删除

- 可下载 CA 证书、私钥或完整证书链（中间 CA + 上级 CA 链）。
- 列表接口不返回证书或私钥内容；私钥下载需要 `private_cas:key`。
- 删除会移除服务端保存的 CA 记录与私钥；存在下级 CA 时需先删除下级 CA。

### 7.4 限制

- 私有 CA 私钥在写入数据库前加密，但不是 HSM/KMS 托管。
- 根 CA 和中间/颁发 CA 都可以在「证书申请」中作为签发机构；完整证书链随证书保存和部署。
- 证书默认有效期 365 天，且不超过 CA 的到期时间。
- CRL/OCSP 分发地址会写入新证书，但实际吊销列表和在线状态服务需要外部 PKI 基础设施提供。
- 存量证书不会自动获得 CDP/AIA 扩展，需要重新签发。

## 8. ACME 服务端

内置 ACME v2 服务端默认开启，可把私有 CA 暴露给 certbot、lego、acme.sh 等客户端。未创建并启用端点时不会签发证书。

### 8.1 端点

- 每个端点绑定一个私有 CA。
- 使用随机 URL slug，例如 `/acme/internal/directory`。
- 支持 EAB 开关、域名白名单、HTTP-01 / DNS-01 / TLS-ALPN-01 能力开关。
- 可独立监听端口，支持直接 TLS 与可选 mTLS。
- 可配置证书有效期、订单限流和 HTTP-01 内网 CIDR 白名单。

### 8.2 协议能力

- 账户只保存公钥，不保存客户端私钥。
- 支持账户密钥轮换（`keyChange`）。
- 支持 ARI（RFC 9773）续期建议：默认在证书到期前约 1/3 生命周期（最多 30 天）给出续期窗口；已撤销或过期证书返回过去窗口以提示立即续期。
- 支持 ARI `replaces` 字段：新订单可声明替换的旧证书，服务端校验旧证书归属、标识重叠和重复替换。
- 支持 DNS 与 IP 标识；IP 标识仅允许 HTTP-01 / TLS-ALPN-01，并要求配置 IP 网段白名单。
- 新签发证书会写入 CRL Distribution Point 和 OCSP AIA 扩展，可通过 `/pki/{ca}/crl` 与 `/pki/{ca}/ocsp` 检查撤销状态。
- 私有 CA 需要具备 `cRLSign` 用途；启用 ACME 端点时会校验。

### 8.3 诊断与清理

- 「ACME 诊断」页面可查看账户、订单、授权、挑战和证书状态。
- 支持按端点、状态和时间清理失效订单与长期未使用账户。
- 清理账户会删除其历史订单，但不会影响已签发的证书。
- CRL/OCSP 按 CA 组织，停用 ACME 报名端点后仍应保持可达（如客户端需要检查吊销）。

## 9. 仪表盘与日志

### 9.1 仪表盘

界面支持简体中文与英文，可在设置中切换。首页汇总：

- 证书总数、即将过期/已过期数量。
- 任务与监控状态。
- 部署成功率。
- 到期分布和签发趋势。

### 9.2 日志：操作日志

- 与系统日志同属「杂项 → 日志」页面，通过顶部页签切换。
- 记录任务执行、证书签发、部署、通知、监控和设置变更。
- 支持按来源、级别和时间范围筛选。
- 可导出 CSV 或 JSON，CSV 带 UTF-8 BOM，可直接用 Excel/WPS 打开。
- 导出范围仅限最近 90 天。
- 导出时间默认跟随浏览器时区；未提供时使用服务端 `TZ`。

### 9.3 日志：系统日志

- 与操作日志同属「杂项 → 日志」页面，通过顶部页签切换。
- 从进程日志中筛选后异步写入数据库。
- 可按级别、组件、关键字和时间范围筛选。
- 可导出 CSV/JSON，并可清空；清空操作会写入操作日志。
- 默认记录 `info` 及以上级别，保留 7 天或 20,000 行。
- HTTP 访问日志默认不写库，可在 `log.system` 中调整。

## 10. 能力边界

| 边界 | 说明 |
| --- | --- |
| 公共证书验证 | 仅 DNS-01；不支持 HTTP-01 向公共 CA 申请 |
| 多用户 | 单管理员账户，无 RBAC/组织架构 |
| 身份联邦 | 无 LDAP/OIDC/SAML/SCIM |
| 高可用 | 无内置集群/双活；SQLite 单写 |
| 私钥托管 | 本地加密存储，无 HSM/KMS |
| 监控输出 | 无 Prometheus 指标端点；提供日志和认证 API |
| 部署回滚 | 不自动回滚目标系统旧证书；需目标侧保留版本 |
| 合规认证 | 不附带等保/ISO 证书；需企业自行测评 |
