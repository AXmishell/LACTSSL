# 功能说明

LACTSSL 把证书生命周期拆成几个模块：用 ACME 申请证书、部署到目标位置、发送通知，并额外监控外部站点的证书。证书申请、部署与通知可以组合进同一个任务流程。

## 证书申请与续期

- 仅使用 **DNS-01** 验证，支持单域名、多域名与通配符证书。
- 内置证书颁发机构：
  - Let's Encrypt
  - ZeroSSL（需要 EAB）
  - Google Trust Services（需要 EAB）
  - Buypass
  - LiteSSL（需要 EAB）
- 私钥类型：`ecdsa`（默认）、`ecdsa384`、`rsa2048`、`rsa4096`。
- 自动续期：默认在到期前 30 天触发，可按任务调整；后台调度器每 30 秒检查一次到期任务。
- 证书管理页支持搜索、按状态筛选、查看详情与安全分析，并可按清理范围（已过期、已撤销或全部）、过期/撤销时长、签发时间、域名、颁发机构、来源以及“保留每个任务最新证书”等条件一键清理证书。
- 可在「权威CA」中填写 ACME 账户邮箱、默认 CA、默认私钥类型、默认续期天数，以及各 CA 的 EAB 凭据。
- 证书申请的颁发机构既可以选择公共 ACME CA，也可以选择「私有CA」中的根 CA 或中间/颁发 CA。选择私有 CA 时由系统直接签发证书，不需要 DNS-01 验证；证书默认有效期 365 天，且不会超过 CA 的到期时间。

## ACME 服务端

内置 ACME v2 服务端可以把私有 CA 暴露给 certbot、lego、acme.sh 等客户端：

- 每个端点绑定一个私有 CA，使用随机 URL slug，例如 `/acme/internal/directory`。
- 支持 EAB 开关、域名白名单、HTTP-01 / DNS-01 / TLS-ALPN-01 能力开关。
- 可独立监听端口，支持直接 TLS 与可选 mTLS。
- 「ACME 服务」管理页面可配置端点、签发 CA、EAB、域名白名单、挑战类型、HTTP-01 内网 CIDR、证书有效期与订单限流，并可创建/删除 EAB 凭据。
- 「ACME 诊断」页面可查看账户、订单、授权、挑战和证书状态，便于排查客户端问题；并支持按端点、状态和时间一键清理失效订单与长期未使用的账户，清理账户会一并删除其历史订单，但不会影响已签发的证书。
- 支持账户密钥轮换（`keyChange`）和 ARI（RFC 9773）续期建议；ARI 默认在证书到期前约 1/3 生命周期（最多 30 天）给出续期窗口，已撤销或过期证书返回过去窗口以提示立即续期。
- 支持 ARI `replaces` 字段：新订单可以声明替换的旧证书，服务端校验旧证书归属、标识重叠和重复替换，并在订单响应中回显。
- 账户只保存公钥，不保存客户端私钥。
- 已实现订单、授权、HTTP-01 / DNS-01 / TLS-ALPN-01 挑战、finalize 签发和证书下载。
- 支持 DNS 与 IP 标识；IP 标识仅允许 HTTP-01 / TLS-ALPN-01，并要求配置 IP 网段白名单。
- 新签发证书会写入 CRL Distribution Point 和 OCSP AIA 扩展，可通过 `/pki/{ca}/crl` 与 `/pki/{ca}/ocsp` 检查撤销状态。
- 私有 CA 需要具备 `cRLSign` 用途；启用 ACME 端点时会校验。存量证书不会自动获得 CDP/AIA 扩展，需要重新签发。

## 私有CA

在「私有CA」中可以管理内部使用的证书颁发机构：

- **生成**：选择私钥类型（ECDSA P-256 / P-384、RSA 2048 / 4096）和有效期，自动生成根 CA；也可以选择「中间/颁发 CA」，由已有私有 CA 签发下级 CA。
- **导入**：粘贴 PEM 格式的 CA 证书与私钥，导入时校验证书的 CA 基本约束、证书签名用途以及证书与私钥是否匹配；导入中间 CA 时可同时选择上级 CA，系统会校验签名并建立层级关系。
- **下载**：可下载 CA 证书、私钥或完整证书链（中间 CA + 上级 CA 链），用于内网服务签发与信任配置。
- **删除**：移除服务端保存的 CA 记录与私钥；存在下级 CA 时需先删除下级 CA。

生成 CA 时还可以展开「高级选项」，配置完整的 X.509 字段与 PKI 参数：

- **证书主题**：ST、L、OU、Email，以及自定义证书序列号。
- **X.509 扩展**：路径长度约束、Key Usage、Extended Key Usage、SAN（DNS / IP）、Name Constraints（允许/排除的 DNS 域与 IP 网段）。
- **PKI 基础设施**：上级 CA、CRL 分发点、OCSP 响应地址、CA 颁发者地址、证书策略 OID 与 CPS 地址。
- 主题密钥标识符（SKI）、颁发机构密钥标识符（AKI）、CA 基本约束等由系统自动生成。
- 选择上级 CA 时，有效期和路径长度会自动收敛到上级 CA 允许的范围。

私有 CA 的私钥在写入数据库前会加密，列表接口不会返回证书或私钥内容。根 CA 和中间/颁发 CA 都可以在「证书申请」中作为签发机构使用，签发的完整证书链会随证书一起保存和部署。CRL / OCSP 分发地址会写入证书，实际的吊销列表与在线状态服务需要由外部 PKI 基础设施提供。

## DNS 服务商

先在「DNS 账户」中添加凭据，再在申请任务中选择。支持：

| 服务商 | 主要凭据 |
| --- | --- |
| 阿里云 DNS（alidns） | AccessKey ID / Secret，可选 Region |
| Cloudflare | API Token，或 Email + Global API Key |
| DNSPod | API Token |
| 腾讯云（tencentcloud） | SecretId / SecretKey，可选 Region |
| DigitalOcean | Token |
| GoDaddy | API Key / Secret |
| Namecheap | API User / API Key，可选 Source IP |
| Vultr | API Key |
| Linode | Token |
| Hetzner | API Key |
| Gandi | API Key |

凭据在写入数据库前会加密。编辑账户时留空密钥字段表示保留原值。

## 证书部署

「目标凭据」只保存认证与连接信息，例如主机、端口、用户名、密码、面板地址和 API Token。证书路径、重载命令、部署域名、站点等参数在「证书申请 → 证书流程 → 部署证书」节点中填写，因此同一个凭据可以被多个任务复用。任务成功签发后可自动部署，也可以手动触发。支持：

- **本地目录**：在部署节点填写证书与私钥路径，可选执行重载命令（如 `systemctl reload nginx`）。
- **SSH / SFTP**：凭据保存主机、端口、用户名及密码或私钥；部署节点填写远程证书/私钥路径，可选远程重载命令。
- **FTP / FTPS**：凭据保存主机、端口、用户名和密码；支持普通 FTP、显式 TLS 与隐式 TLS（FTPS），部署节点填写远程证书/私钥路径。
- **Webhook**：凭据保存回调地址、自定义认证头与是否跳过 TLS 校验。
- **阿里云 CDN**：凭据保存 AccessKey；部署节点填写要更新的域名与自定义证书名称。
- **七牛云 CDN**：凭据保存 AccessKey / SecretKey；部署节点填写加速域名与证书名称，域名未开启 HTTPS 时会自动开启。
- **七牛云 Kodo**：凭据保存 AccessKey / SecretKey；部署节点填写对象存储自定义源站域名与证书名称。
- **宝塔面板网站**：凭据保存面板地址与 API Secret；部署节点填写要部署的网站名称。
- **宝塔面板 SSL 证书**：凭据保存面板地址与 API Secret，用于替换宝塔面板自身使用的 SSL 证书。
- **1Panel 网站**：凭据保存面板地址、API Key 与 API 版本；部署节点填写网站域名、别名或 ID。
- **1Panel 面板**：凭据保存面板地址、API Key 与 API 版本；部署节点选择 Enable / Mux 模式。
- **雷池 WAF**：凭据保存面板地址与 API Token；部署节点可指定证书 ID，留空时按证书域名自动匹配。

每次部署都会生成部署记录，可在证书详情和日志中查看结果。手动部署时会优先复用证书所属任务的部署节点参数，也可以按目标单独填写本次部署参数。

## 通知

内置渠道：

- **邮件（SMTP）**：服务器、端口、用户名、密码、发件人，支持 SSL。
- **Gotify**：服务地址、Token、优先级。
- **ServerChan**：SendKey，支持 Turbo / Server酱³ / 自动识别。

扩展渠道：

ntfy、GoCQHTTP、PushDeer、Bark、Telegram、钉钉、企业微信机器人、企业微信应用、企业微信智能机器人、iGot、PushPlus、WePlus、WxPusher、WxPusher SPT、OpenILink、WPush、Synology Chat、飞书、PushMe、ChronoCat，以及通用自定义 Webhook。

渠道可以单独启用并发送测试消息。任务的通知节点可选择具体渠道，或使用全部已启用渠道；触发时机支持始终、仅成功、仅失败。

## 站点证书监控

添加外部站点后，服务会定期通过 TLS 连接读取证书：

- 目标支持 `example.com`、`example.com:8443` 或完整 URL，默认端口 `443`。
- 默认每 24 小时检查一次，可按监控项调整。
- 校验证书主机名，记录签发者、到期时间与状态。
- 剩余 30 天以内标记为即将过期；过期、连接失败或主机名不匹配会标记为异常。
- 状态从正常变为即将过期、已过期或异常时，发送通知。

## 任务流程

任务的执行流程由节点组成，默认是「申请 → 部署（可多个）→ 通知」：

- **申请**：域名、DNS 账户、CA、私钥类型、自动续期与提前天数。
- **部署**：选择一个目标凭据，并填写本次部署的证书路径、站点、域名等参数。
- **通知**：选择渠道与触发时机。

节点可以启用/禁用和排序。旧任务没有显式流程时，会根据原有域名、目标凭据等字段自动推导出等效流程。升级时会先把旧凭据中的部署路径、站点和域名迁移到任务部署节点，再清理凭据中的部署参数。

任务列表支持表头全选和多选，可对选中任务批量执行、暂停或启动自动续期。批量执行会跳过正在运行的任务，批量启停只调整调度状态，不会中断已经开始的签发。

## 仪表盘与日志

首页汇总证书总数、即将过期/已过期数量、任务与监控状态、部署成功率、到期分布和签发趋势。任务执行、部署、通知、监控和设置变更都会写入系统日志，可在界面中筛选查看。

## 界面

支持简体中文与英文，可在设置中切换。「系统设置 → 备份与恢复」可以下载经过密码加密的 ZIP 备份包（包含数据库与配置文件），或上传备份包恢复系统数据；首次安装时也可在 `/install` 的高级功能中直接导入备份。安全相关能力见[安全](security.md)。
